# 拼豆像素工坊

一个纯前端的网页工具：把你想拼的图片转换成拼豆像素图，再逐格精确修改，最后导出带色号的图纸和用料清单。

不依赖任何第三方库，也不需要构建步骤，数据都保存在浏览器本地。

## 运行

```bash
npm start          # 等同于 node server.js，默认 http://localhost:8080
```

也可以用任意静态服务器托管整个目录（例如 GitHub Pages）。
因为用了 ES Module，直接双击打开 `index.html` 时浏览器会拦截脚本，所以需要通过 http 访问。

## 功能

**图片 → 像素图**
- 点击、拖入或粘贴图片
- 设置宽 × 高（颗），可以按原图比例自动算高度
- 按色卡匹配颜色（CIEDE2000 色差，比直接比 RGB 更接近人眼感受）
- 限制最多使用的颜色数，自动合并差别最小、用量最少的颜色
- 亮度、对比度、饱和度调整
- 从边缘自动去除背景、清除孤立杂点、可选抖动
- 生成后、手动编辑之前调参数，画布会实时刷新；生成操作可以撤销

**精确编辑**
- 工具：铅笔 (B)、橡皮 (E / 鼠标右键)、填充 (G，按住 Shift 替换全部同色)、吸管 (I / Alt+点击)、直线 (L)、矩形 (R，按住 Shift 画实心)、移动 (H / 按住空格拖动)
- 滚轮缩放、触屏双指缩放；`+` `-` 缩放，`0` 适应窗口
- 左右 / 上下对称绘制
- 网格线、拼豆板分界线（10 / 14 / 29 / 50 / 52）、在格子里显示色号
- 状态栏显示鼠标所在的行列和颜色
- 调整画布尺寸、翻转、整体平移内容
- 撤销 / 重做（Ctrl+Z / Ctrl+Shift+Z），最多 200 步

**用料与导出**
- 实时统计每种颜色的颗数；点击某种颜色可以高亮，方便逐色拼
- 一键把某种颜色全部替换成当前颜色
- 导出：带坐标、色号、拼豆板分界和用料清单的打印图纸 PNG；任意倍数的像素图 PNG；用料 CSV
- 保存 / 打开项目文件（.json），并且自动保存到浏览器

## 色卡

内置「通用 48 色」和「Perler（近似色值）」两套色卡。
**品牌色卡里的色值是近似值**，和实物会有色差。要做到精确，建议在「导入 / 管理色卡」里粘贴你自己的色卡（例如 MARD、Hama、Artkal 等），每行一种颜色：

```
A1,#FAF4E8,奶白
A2 #FFF6D4 浅黄
#FF0000
```

可以用「载入当前色卡做底稿」复制一套再修改。

## 代码结构

```
index.html        页面结构
css/style.css     样式（自动适配深色模式和手机屏幕）
js/main.js        界面逻辑、快捷键、自动保存
js/editor.js      画布渲染、缩放平移、绘图工具、撤销重做
js/convert.js     图片采样、去背景、颜色匹配与合并、抖动
js/color.js       RGB / Lab 转换、CIEDE2000 色差
js/palettes.js    内置色卡、色卡文本解析
js/export.js      导出图纸 / PNG / 项目文件
server.js         本地预览用的静态服务器
```
