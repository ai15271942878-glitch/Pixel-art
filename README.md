# 拼豆像素工坊

一个纯前端的网页工具：把你想拼的图片转换成拼豆像素图，再逐格精确修改，最后导出带色号的图纸和用料清单。

不依赖任何第三方库，也不需要构建步骤，数据都保存在浏览器本地。

## 运行

```bash
npm start          # 等同于 node server.js，默认 http://localhost:8080
```

也可以用任意静态服务器托管整个目录。

## 分享给朋友（GitHub Pages，免费）

整个项目是纯静态网页，可以直接用 GitHub Pages 发布：

1. 把代码合并到 `main` 分支
2. 打开仓库的 **Settings → Pages**
3. **Source** 选 **Deploy from a branch**，**Branch** 选 `main`、目录选 `/ (root)`，点 **Save**
4. 等一两分钟，页面顶部会出现网址：`https://ai15271942878-glitch.github.io/Pixel-art/`

以后每次推送到 `main`，网页都会自动更新。每个人的作品和自定义色卡只保存在自己的浏览器里，不会互相看到。
因为用了 ES Module，直接双击打开 `index.html` 时浏览器会拦截脚本，所以需要通过 http 访问。

## 功能

**图片 → 像素图**
- 点击、拖入或粘贴图片
- 设置宽 × 高（颗），可以按原图比例自动算高度
- 按色卡匹配颜色（CIEDE2000 色差，比直接比 RGB 更接近人眼感受）
- 限制最多使用的颜色数，自动合并差别最小、用量最少的颜色
- 亮度、对比度、饱和度调整
- 从边缘自动去除背景、清除孤立杂点、可选抖动
- 生成后、手动编辑之前调参数，画布会实时刷新；生成操作可以撤销
- 调乱了可以点「恢复默认参数」，尺寸和色卡不变，其余参数回到初始值

**精确编辑**
- 工具：铅笔 (B)、橡皮 (E / 鼠标右键)、填充 (G，按住 Shift 替换全部同色)、吸管 (I / Alt+点击)、直线 (L)、矩形 (R)、圆 / 椭圆 (O)、移动 (H / 按住空格拖动)；画矩形和椭圆时按住 Shift 画实心
- 笔刷 1×1 / 2×2 / 4×4 / 8×8（`[` `]` 切换），从落点向右下扩展，作用于铅笔、橡皮和描边图形
- 滚轮缩放、触屏双指缩放；`+` `-` 缩放，`0` 适应窗口
- 左右 / 上下对称绘制
- 网格线、拼豆板分界线（默认不显示，可选 10 / 14 / 29 / 50 / 52）、在格子里显示色号
- 状态栏显示鼠标所在的行列和颜色
- 调整画布尺寸、翻转、整体平移内容
- 撤销 / 重做（Ctrl+Z / Ctrl+Shift+Z），最多 200 步

**用料与导出**
- 实时统计每种颜色的颗数；点击某种颜色可以高亮，方便逐色拼
- 一键把某种颜色全部替换成当前颜色
- 导出打印图纸 PNG：四边序号带、逐格色号、黑色计数线（从中心向外每 10 格，或从左上角每 5 格）、拼豆板分界和用料清单；可以限制最长边 2048 像素，发小红书等平台时不会被压糊
- 导出任意倍数的像素图 PNG、用料 CSV
- 空格和白色豆严格区分：空格不放豆、不标号、不计数
- 保存 / 打开项目文件（.json），并且自动保存到浏览器

## 色卡

内置色卡：

| 色卡 | 说明 |
| --- | --- |
| MARD 221 色（默认） | MARD 标准 A–H + M 全套 |
| MARD 144 色 / 24 色 | 221 色的子集，同一色号的名称和色值完全一致 |
| Perler（近似色值） | 33 种常用色 |
| 通用 48 色 | 不对应具体品牌 |

MARD 色表的名称和色值整理自 [beiyapd.com](https://beiyapd.com/zh-CN/bead-tools#mard)，参考了 [PixelDraw](https://github.com/HHpetra/PixelDraw) 的收录，详见 [THIRD_PARTY.md](THIRD_PARTY.md)。
**屏幕色值只是参考**，和实物会有色差。要做到精确，可以在「导入 / 管理色卡」里粘贴你按实物校准过的色卡，每行一种颜色：

```
W01,#FAF4E8,我的奶白
W02 #FFF6D4 我的浅黄
#FF0000
```

可以用「载入当前色卡做底稿」复制一套再修改。

## 代码结构

```
index.html        页面结构
css/style.css     样式（自动适配深色模式和手机屏幕）
js/main.js        界面逻辑、快捷键、自动保存
js/editor.js      画布渲染、缩放平移、绘图工具、撤销重做
js/convert.js     图片采样、去背景、颜色匹配与合并、抖动
js/color.js       RGB / Lab 转换、CIEDE2000 色差
js/palettes.js    内置色卡、色卡文本解析
js/palettes-mard.js  MARD 221 / 144 / 24 色表
js/export.js      导出图纸 / PNG / 项目文件
server.js         本地预览用的静态服务器
```
